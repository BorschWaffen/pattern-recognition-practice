1. **Що таке Google Colab?**  
   Хмарне середовище від Google для створення та виконання Jupyter Notebook безпосередньо у браузері без необхідності локально встановлювати Python та додаткові бібліотеки.

2. **Що таке Jupyter Notebook?**  
   Інтерактивний документ (файл із розширенням `.ipynb`), який поєднує програмний код, результати його виконання (текст, таблиці, графіки) та форматовані текстові пояснення у форматі Markdown.

3. **Які два основні типи комірок використовуються в Notebook?**  
   Комірки з кодом (**Code** — для написання та виконання коду Python) та текстові комірки (**Text** — для заголовків, описів, постановки задачі та висновків у форматі Markdown).

4. **Як запустити комірку?**  
   Натиснути кнопку запуску (іконку відтворення) ліворуч від комірки або скористатися комбінацією клавіш `Shift + Enter`.

5. **Для чого призначений файл `README.md`?**  
   Це головний інформаційний файл репозиторію або окремої папки, у якому зазначають назву та призначення проєкту, відомості про автора, структуру файлів, інструкції із запуску та опис виконаних робіт.

6. **Що таке pandas DataFrame?**  
   Двовимірна іменована таблична структура даних у бібліотеці `pandas`, що складається з рядків (індексів) та стовпців, які можуть містити дані різних типів.

7. **Що є рядком таблиці?**  
   Горизонтальний запис таблиці, який відповідає одному досліджуваному об'єкту та містить значення його характеристик і цільової змінної.

8. **Що є стовпцем таблиці?**  
   Вертикальна колонка таблиці, яка відповідає певній ознаці (характеристиці) або цільовій змінній для всіх об'єктів вибірки.

9. **Що таке об'єкт у задачі машинного навчання?**  
   Один окремий досліджуваний приклад або спостереження, для якого фіксуються ознаки (один рядок таблиці даних).

10. **Що таке ознака?**  
    Окрема характеристика або властивість об'єкта, на основі якої виконується аналіз і будується прогноз (один стовпець матриці ознак `X`).

11. **Що таке цільова змінна?**  
    Величина або категорія (`y`), яку модель машинного навчання повинна навчитися прогнозувати за вхідними ознаками об'єкта.

12. **Що є об'єктом у наборі Iris?**  
    Одна окрема квітка ірису, для якої виміряно розміри чашолистка та пелюстки.

13. **Які ознаки містить набір Iris?**  
    Чотири числові ознаки (у сантиметрах):
    - довжина чашолистка (`sepal_length_cm`);
    - ширина чашолистка (`sepal_width_cm`);
    - довжина пелюстки (`petal_length_cm`);
    - ширина пелюстки (`petal_width_cm`).

14. **Яка цільова змінна використовується у роботі?**  
    Стовпець `species`, що позначає вид квітки ірису (`setosa`, `versicolor` або `virginica`).

15. **Чому задача Iris є задачею класифікації?**  
    Тому що цільова змінна приймає дискретні категоріальні значення (належність до одного з фіксованого переліку видів ірису), а не неперервні числові значення.

16. **Чому ця задача є багатокласовою?**  
    Тому що цільова змінна містить більше ніж два класи — а саме **три** класи (`setosa`, `versicolor`, `virginica`).

17. **Для чого використовується метод `head()`?**  
    Для виведення перших рядків таблиці DataFrame з метою швидкого ознайомлення зі структурою та вмістом даних (за замовчуванням повертає перші 5 рядків).

18. **Для чого використовується метод `tail()`?**  
    Для виведення останніх рядків таблиці DataFrame (за замовчуванням повертає останні 5 рядків).

19. **Що повертає властивість `shape`?**  
    Кортеж із двох цілих чисел у форматі `(кількість_рядків, кількість_стовпців)`, наприклад `(150, 5)` для підготовленої таблиці Iris.

20. **Для чого використовується метод `info()`?**  
    Для отримання зведеної технічної інформації про DataFrame: кількості рядків і стовпців, назв стовпців, кількості непорожніх (`non-null`) значень, типів даних кожного стовпця та обсягу використаної оперативної пам'яті.

21. **Яку інформацію повертає метод `describe()`?**  
    Основну описову статистику для числових стовпців: кількість непорожніх значень (`count`), середнє арифметичне (`mean`), стандартне відхилення (`std`), мінімальне значення (`min`), квартилі (`25%`, медіану `50%`, `75%`) та максимальне значення (`max`).

22. **Як знайти пропущені значення?**  
    За допомогою методів `data.isna()` або `data.isnull()`. Для підрахунку кількості пропусків по кожному стовпцю використовують `data.isna().sum()`, а загальної кількості по всій таблиці — `data.isna().sum().sum()`.

23. **Як перевірити наявність дублікатів?**  
    Викликати метод `data.duplicated()`, а для визначення загальної кількості повністю однакових рядків — `data.duplicated().sum()`.

24. **Для чого використовуються гістограми?**  
    Для візуалізації та первинного дослідження розподілу значень числових ознак: оцінки діапазону значень, частоти їх появи, форми розподілу, наявності кількох груп (мод) або аномальних значень.

25. **Чому важливо аналізувати розподіл об'єктів за класами?**  
    Щоб перевірити збалансованість вибірки: значний дисбаланс класів може призвести до того, що модель погано розпізнаватиме рідкісні класи, а також впливає на вибір метрик оцінювання якості.

26. **Чим ознаки `X` відрізняються від цільової змінної `y`?**  
    `X` — це матриця вхідних ознак (характеристик об'єктів розмірністю `(150, 4)`), на основі яких робиться прогноз, тоді як `y` — це вектор цільової змінної (відповідей розмірністю `(150,)`), яку потрібно передбачити.

27. **Чому важливі дані потрібно зберігати на Google Drive або GitHub?**  
    Оскільки середовище виконання Google Colab є тимчасовим і після завершення або перезапуску сеансу всі локальні файли в ньому видаляються, тоді як Google Drive і GitHub забезпечують надійне постійне зберігання файлів та контроль версій.

28. **Чому перед здаванням необхідно повторно виконати всі комірки?**  
    Щоб гарантувати, що код у Notebook виконується послідовно зверху вниз без помилок (`NameError`, `FileNotFoundError` тощо), а в документі збережено всі актуальні таблиці, графіки та результати виведення.
